# MDX reference assets

Source website: https://mdx.so/

These files support the user's explicitly selected close MDX recreation for a local UniMatch preview. They are reference assets from MDX's publicly served site; they are not original UniMatch artwork. This manifest records provenance, not a grant of rights from the original authors.

Only frame zero of each orientation is retained as historical reference. Home's current hero generates its own particle geometry and uses a loading screen, not an image poster or a downloaded frame sequence. There is no reference asset fetch script in this repository. Sound is off until explicitly activated by the visitor.
