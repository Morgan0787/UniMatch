# UniMatch agent entrypoint

Use `docs/agents/context/README.md` to choose context by task; read only the documents needed for the affected area. For imports, matching, university displays, auth access rules, or schema changes, apply `docs/agents/context/DECISIONS.md`.

For source, test, script, or documentation edits, read `CODING_STANDARDS.md`. For implementation planning, delegation, or resuming multi-batch work, follow `docs/agents/WORKFLOW.md`; this project authorizes the subagent work specified there.

Before completing a change, apply `docs/agents/context/MAINTENANCE.md` to decide which documentation needs updating. For switching tools or agent settings, read `docs/agents/README.md`.
